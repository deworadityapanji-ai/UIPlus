# Bundled title background

`Nuclear Option Title - At0micVen0m_.mp4` is supplied locally for release builds. It is by
[At0micVen0m_ (Atomic)](https://www.youtube.com/@At0micVen0m_) and is included with permission.
[Watch the original video on YouTube.](https://www.youtube.com/watch?v=tATPDavr1fo)

Release maintainers can place the supplied MP4 next to this README before running
`scripts/package.ps1`. The package places it in `UIPlus/Backgrounds/`, relative to
`BepInEx/plugins/`. Players can remove or replace the file there, or turn off **Custom background**
in the UI PLUS settings.
